# SocialHub

A Social Media Management SaaS platform built with Laravel and MySQL, allowing users to manage multiple social media accounts from a single dashboard.

## Features

- Admin Dashboard
- User Management
- Multi Social Account Management
- Post Scheduling
- Content Calendar
- Client Management
- Team Management
- Analytics Dashboard
- Billing Management

## Tech Stack

- PHP
- Laravel
- MySQL
- Blade
- HTML5
- CSS3
- JavaScript

## Project Structure

- Admin Panel Layout
- Dashboard Controller
- Reusable Components
  - Header
  - Sidebar
  - Footer
- Database Migrations
- User Management System

## Installation

```bash
git clone <repository-url>
cd socialhub

composer install

cp .env.example .env

php artisan key:generate

php artisan migrate

php artisan serve
```
